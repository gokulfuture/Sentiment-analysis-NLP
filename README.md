# Sentiment-analysis-NLP
Project Overview
The project demonstrates the application of Natural Language Processing in sentiment analysis. A Twitter airline sentiment dataset was used to classify text into positive, negative and neutral categories.A Logistic Regression classifier was trained and evaluated using accuracy, precision, recall, F1-score and a confusion matrix.


Objective

To classify short text sentences into positive and negative sentiments.

Tools and Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- NLP

Project Files

- Sentiment_analysis.ipynb – Google Colab notebook containing the implementation and analysis.
